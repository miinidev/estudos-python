# Calculadora em Python

Projeto de terminal desenvolvido durante os estudos de Python.

## Funcionalidades

- Soma
- Subtração
- Multiplicação
- Divisão
- Validação de entradas numéricas
- Verificação de divisão por zero

## Como executar

Com Python 3 instalado, execute no terminal, a partir da raiz do repositório:

```bash
python projetos/calculadora/Calculadora.py
```

Em alguns ambientes, use `python3` no lugar de `python`.

## Conceitos praticados

- Variáveis e entrada de dados
- Condicionais
- Laços de repetição
- Funções
- Tratamento de exceções
