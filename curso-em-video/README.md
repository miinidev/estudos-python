# Curso em Vídeo — Python

Esta pasta reúne os exercícios feitos durante o curso de Python do **Curso em Vídeo**, do professor Gustavo Guanabara.

Os arquivos devem ser organizados de acordo com o mundo e a aula em que o conteúdo foi estudado.

## Organização

- `mundo-1/` — conteúdos e exercícios do primeiro mundo.
- `mundo-2/` — conteúdos e exercícios do segundo mundo.
- `mundo-3/` — conteúdos e exercícios do terceiro mundo.

Registre aqui apenas exercícios que você realmente desenvolveu. Se adaptar uma solução apresentada na aula, deixe isso indicado no comentário ou no README correspondente.
